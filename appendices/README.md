# Appendices

Simpan sumber lampiran LaTeX di direktori ini. Gunakan nama berkas huruf kecil yang deskriptif, misalnya `appendix-test-results.tex`, lalu muat dari alur lampiran dokumen utama yang sudah tersedia.

Jangan simpan output kompilasi di sini; output sementara harus berada di `build/`. Lampiran biner yang hanya perlu didistribusikan, bukan di-`\input`, ditempatkan di `assets/attachments/`.
