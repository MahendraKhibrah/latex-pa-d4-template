# Attachments

Simpan lampiran biner pendukung yang perlu dipelihara bersama laporan, misalnya lembar data, hasil pengujian bertanda tangan, atau dokumen referensi yang memiliki izin distribusi.

Gunakan nama huruf kecil dengan tanda hubung dan dokumentasikan asal, tanggal, lisensi, serta keterkaitannya dalam `artifacts/`. Jangan simpan rahasia, data pribadi yang tidak diperlukan, atau output build sementara di direktori ini.
