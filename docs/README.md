# Workflow Documentation

Dokumentasi ini menjelaskan kontrak operasional di sekitar sumber LaTeX tanpa mengubah struktur template inti.

- [`workflow.md`](workflow.md) — alur build, watch, check, evaluation, clean, dan direktori output.
- [`metadata.md`](metadata.md) — metadata dokumen/artifact serta konvensi tanggal.
- [`release.md`](release.md) — penamaan dan prosedur rilis yang dapat diverifikasi.
- [`2026-10-04_arsitektur-template.md`](2026-10-04_arsitektur-template.md) — keputusan arsitektur awal template.

Semua dokumen selain `README.md` wajib memakai YAML front matter dengan `created_at` dan nama `YYYY-MM-DD_nama-dokumen`. Dokumen lama tanpa prefix tanggal dipertahankan sebagai dokumentasi inti project.
